Every mod installs the same way

  1. In a Claude Code terminal session, type this at the prompt, with the mod's name in place of <mod>:

    /plugin install <mod> --marketplace aseem-upadhyay/qol-mods

  2. Answer y to add the marketplace (only the first time), then pick the user scope so the mod loads in every session.

  3. That's it. Installing from a terminal also loads the mod in the desktop app's Code tab. Each mod's page has its exact command.

The mods need macOS or Linux and python3 3.9 or newer. Windows isn't supported yet.

Questions about Claude Code mods

What are Claude Code mods?

Mods are plugins that change how Claude Code looks or behaves: a pane beside the chat, a bar above the prompt, a new slash command, a hook on tool calls. The quality of life mods here each add something Claude Code doesn't show you on its own, like your standup, a repo's running cost or the habit to work on next.

Are they free?

Yes. Every mod is free and open source under the MIT license, and the code is on GitHub for you to read before you install.

Does anything leave my machine?

No. The mods read the session logs Claude Code already keeps and make no network calls of their own. The only exceptions are opt-in: coach can grade your prompts with a model, and worklog can read your pull requests through your gh login.

Do they work in the Claude desktop app?

Yes. Install a mod once from a terminal session and it loads in the terminal and in the desktop app's Code tab.

How do I install or remove a mod?

Install with /plugin install <mod> --marketplace aseem-upadhyay/qol-mods (see the steps above). Remove one with claude plugin uninstall <mod>@qol-mods.

What do I need to run them?

macOS or Linux, and python3 3.9 or newer. Windows isn't supported yet.
