Every mod installs the same way

  1. In a Claude Code terminal session, type this at the prompt, with the mod's name in place of <mod>:

    /plugin install <mod> --marketplace aseem-upadhyay/qol-mods

  2. Answer y to add the marketplace (only the first time), then pick the user scope so the mod loads in every session.

  3. That's it. Installing from a terminal also loads the mod in the desktop app's Code tab. Each mod's page has its exact command.

The mods need macOS or Linux and python3 3.9 or newer. Windows isn't supported yet.
